# Phase 6 iPhone / Android 実機テスト

## 推奨
- Safari / Chrome
- 横画面
- 844x390前後、932x430前後を優先

## 確認1 — 横画面ゲームシェル
1. 新規ゲームを開始。
2. 横画面でページ全体が縦に長くスクロールしないこと。
3. 下部の「地図 / 城 / 軍議 / 次季 / メニュー」が親指で押しやすいこと。
4. 地図・城・軍議を切り替えても状態が失われないこと。

## 確認2 — 地図操作
1. 地図で自軍城をタップ。
2. 下部に選択城ドックが出ること。
3. 「詳細」で城画面、「出陣」でArmy編成へ入れること。
4. Army/包囲マーカーが城ドックや下部ナビに隠れすぎないこと。

## 確認3 — 内政/軍議
1. 城タブで人口・守備兵・農業・収支・武将・命令が確認できること。
2. 町づくり/開墾/徴兵/訓練/休養/偵察/出陣をタップできること。
3. 軍議タブで家臣提案を確認・採用できること。

## 確認4 — 次季
1. 下部「次季」を押す。
2. 従来の「季節を進める」と同じ結果になること。
3. Army到着時にTactical Battleへ正しく切り替わること。
4. Tactical終了後、戦略画面へ復帰できること。

## 確認5 — 縦画面
ゲーム中に縦へ回転し、「横向きでプレイしてください」が全面表示されること。横へ戻すとゲーム状態を失わず復帰すること。

## 手動合格基準
- 誤タップが少ない
- 横画面で主要操作にページスクロールが不要
- 戦略→Tactical→戦略の遷移が破綻しない
- iPhoneのノッチ/Dynamic Island/Home Indicatorに主要ボタンが被らない
