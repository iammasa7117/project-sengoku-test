# Project Sengoku Phase 7 — スマホ実機テスト手順

## 推奨環境

- iPhone Safari / ホーム画面追加
- Android Chrome
- **横画面**

## 最優先で試すこと

### 1. 城の個性

地図で複数の城をタップし、城アイコン・城種・固有タイトルが違うことを確認してください。

城詳細で「街道商都」「湊の交易地」「高地要塞」「山道の要衝」などのプロフィールが読めるか確認します。

### 2. 奉行

自勢力城を開き、待機武将を奉行へ任命してください。

確認:

- 奉行チップが表示される
- 季節収入や人口成長の補正が変わる
- 1城に奉行が2人入らない

### 3. 城に残すか、戦場へ出すか

奉行をArmy編成に選び出陣させてください。

確認:

- Army編成画面に現在役割が表示される
- 出陣後はその城の奉行から外れる
- 城の内政ボーナスが消える

城主についても、出陣させた場合の役割喪失警告が理解できるか見てください。

### 4. 複数区間進軍

自勢力の中継城を挟んだ敵城を出陣先に選んでください。

出陣画面で、

`出発城 → 友軍中継城 → 敵城`

のルートと所要季節が表示されることを確認します。

### 5. 山道

山城を含むルートでは、一部区間が通常より長くかかります。

- ETAが増える
- 季節を1回進めても中継/目的地へ即到達しないケースがある

ことを確認してください。

### 6. 攻城

守りの強い城へ攻め、城プロフィール・城主による守備補正が攻城画面に反映されているか確認します。

### 7. Tactical回帰

プレイヤーArmyで敵城へ到達してリアルタイム会戦を開始してください。

- 横画面全画面でB5.3が開く
- 指で部隊を動かせる
- FLANK / REAR / CHARGEが従来どおり機能する
- 戦闘結果がCoreへ戻る

## 特に教えてほしい感想

1. 城ごとの違いをすぐ理解できるか
2. 「この武将は城に残したい」と思えるか
3. ルートとETAは分かりやすいか
4. マップ上の情報量が多すぎないか
5. 出陣画面がスマホ横画面で窮屈でないか
6. もっと欲しい城の個性は何か

実機で違和感がある箇所はスクリーンショットを送ってください。Phase 8より先にUIだけ直すべき重大な問題か判定します。
