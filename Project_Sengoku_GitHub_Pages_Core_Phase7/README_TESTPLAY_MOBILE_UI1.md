# Phase UI-1 スマホ実機テスト

iPhone / Androidを横画面にして開始してください。

1. 自軍の城を選ぶ → 「城」タブ
   - 城画像が大きく見える
   - 城名 / 城主 / 人口 / 守備兵 / 民忠 / 防備が一目で分かる
   - 下部に「内政 / 家臣一覧 / 人材登用 / 出陣」の4ボタンが見える
2. 「内政」
   - 大きな画像付きコマンドタイルが4列で見える
   - 新田開発 / 商業投資 / 軍事訓練など意味が直感的に分かる
   - 城強化 / 建設は準備中と明示される
3. 「家臣一覧」
   - 武将画・名前・能力4種・忠誠・兵力が比較しやすい
   - 武将をタップして従来の詳細画面へ進める
4. 「人材登用」
   - 候補がいない場合でも、何の画面か理解できる空状態が表示される
   - 捕虜がいる場合は既存の登用交渉へ進める
5. 「出陣」
   - 従来のArmy Plannerが正常に開く
6. 戦闘
   - Core→Tactical→Coreがこれまで通り動く

確認したい感想：
- 以前より「戦国ゲームを遊んでいる」ことが一目で分かるか
- 文字が小さすぎないか
- 4主要ボタンの位置は自然か
- 内政タイルを押しやすいか
- 家臣一覧で能力比較がしやすいか
