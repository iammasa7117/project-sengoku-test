# Phase 11 スマホ実機テスト — Pursuit Doctrine

横画面で`01_START_GAME.html`を開いてください。

## 最短確認

1. AI有効の通常戦役を開始。
2. 敵Armyが自城へ接近するまで季節を進める。
3. 敵Armyを迎撃する。
4. Field Battleに勝利する。
5. 戦報の「追撃可能」を確認。
6. 「騎馬比率」「予想追加損害」「総大将疲労」が表示されることを確認。
7. 「追撃する」を選択。
8. 敗走軍の追加損害と戦後結果を確認。

## 比較してほしい点

同じ総大将で、迎撃Armyの兵種を変えて比較する。

### 足軽主体
追撃効果が比較的低くなる。

### 騎馬主体
追撃効果が高くなり、追撃疲労も軽くなる傾向を確認。

## AI側の確認

弱い迎撃軍を出し、AIに野戦で勝たせる。

- AIが条件を満たす場合、敗走Player Armyへ追加損害が発生する。
- AI総大将の疲労が高い場合は「深追いを避けた」と戦報に表示される場合がある。
- AI追撃で城所有権が直接変化しない。

## 既存機能確認

- 敗走Armyの「退」旗が表示される。
- 敗走Armyは次季に自城へ帰還する。
- Siege Tacticalは従来どおり動く。
- Save / Load後も未解決のPlayer追撃判断を続けられる。
