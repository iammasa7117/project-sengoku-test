# Phase 4 — iPhone / Android 実機テスト

## 推奨
GitHub Pages版をSafari/Chromeで開き、端末を横向きにしてください。ホーム画面追加時もlandscape manifestを維持しています。

## 最短テスト
1. 新しい戦役を開始。
2. 戦争中の敵城に隣接する自城を選択。
3. 「侵攻/軍勢編成」から1〜3武将を選び、足軽・騎馬・鉄砲・侍と兵数を設定して出陣。
4. 戦略マップに「軍」マーカーが出ることを確認。
5. 「季節を進める」。敵城へ到着するとCore画面ではなくTactical会戦が全画面で開く。
6. Tacticalでは自軍Unitをタップし、指で経路を描く。敵へドラッグして攻撃。騎馬でFLANK/REARを狙う。
7. 会戦終了後、メニュー内の「戦略画面へ結果を戻す」を押す。
8. Coreへ戻り、戦闘報告、残存兵、城所有権、季節進行を確認。

## 特に見てほしい点
- Core→Tacticalの切替で白画面/画面崩れがないか。
- iPhoneノッチ/Dynamic Islandで上部HUDが切れないか。
- Coreで選んだ武将名・兵種がTactical rosterへ反映されるか。
- Coreの兵力20〜40程度がTacticalでは500〜1000程度に表示されること（Adapterの25倍表示スケール、仕様どおり）。
- 戦闘後、損害がCoreの小さい兵力単位へ自然に戻るか。
- 勝利時は敵城を占領、敗北/引分時はArmyが出陣元へ戻るか。
- 会戦中にページを再読込→「続きから」で同じpending会戦を再開できるか。

## 現在の意図的制限
- Tacticalはプレイヤー主導攻撃だけ。AI戦はLegacy自動解決。
- Army plannerは最大3 Unit。7v7/20v20拡張は後工程。
- Phase 4では野戦勝利=即落城。Siegeの本接続はPhase 5。
- Tactical途中のCore操作/セーブUIは出さない。
