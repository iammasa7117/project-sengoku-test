# Phase 12 スマホ実機テスト — Pursuit Risk / Capture & Escape

## 推奨
iPhone / Androidで `01_START_GAME.html` を横画面で開く。

## 最短確認
1. AI有効の通常戦役を開始。
2. 敵Armyが自城の最終隣接区間へ入るまで「次季」。
3. 敵Armyをタップし「迎撃軍を出す」。
4. できれば騎馬を多めに含む迎撃軍を編成。
5. 街道野戦で勝利する。
6. Battle Reportの追撃カードを確認。
7. 「予想追加損害」「捕縛見込み」「深追いリスク」「総大将疲労」が読めることを確認。
8. 「追撃する」を選ぶ。
9. 追撃結果に、追加損害に加えて「敵将逃亡」または「捕縛」が表示されることを確認。
10. 深追い事故が出た場合、総大将の疲労/体力/軽傷表示を確認。

## 捕縛が発生した場合
- 敵敗走Armyが地図から消え、残兵が退却先へ散開帰還すること。
- 捕縛武将が「捕虜処遇 / 人材登用」の候補へ入ること。
- 登用・解放など既存捕虜機能へ進めること。

## 見てほしいUX
- 数値が多すぎず「追う価値 / 危険」が理解できるか。
- 「追撃せず戻る」が安全な選択肢として認識できるか。
- 捕縛時に成果が十分大きく感じられるか。
- 深追い事故が理不尽すぎないか。

## 注意
捕縛・深追い事故は確率要素なので通常プレイでは毎回発生しません。
