# Phase 5 / Playable Sengoku Loop v0.1 — 携帯実機テスト

対象: iPhone / Android、**横画面推奨**。

GitHub Pages版をSafari/Chromeで開いてください。ホーム画面追加時もLandscape指定を維持しています。

## 最優先で確認する一周

1. 新しい戦を開始。
2. 自勢力の城を選択。
3. 内政画面で人口・農業・金・兵糧・守備兵を確認。
4. 「侵攻」からArmyを編成。武将・兵種・兵数を指定して出陣。
5. 地図上にArmyマーカーが出ることを確認。
6. 季節を進め、敵城へ到着。
7. Tactical B5.3が全画面で開くことを確認。
8. 部隊を指で選択し、ドラッグ経路・FLANK/REAR/CHARGEを試す。
9. 勝利後「戦略画面へ結果を戻す」。
10. 次のどちらかを確認。
    - 圧勝: `🏯 落城` → 城が自領になる。
    - 僅差: `🛡️ 包囲継続` → 地図上に「囲」Armyが残る。
11. 包囲継続ならArmyをタップし、攻城力/城防御メーターを見る。
12. そのまま季節を進め、守備兵/防備が削れ、最終的に落城することを確認。
13. あるいは「包囲を解いて撤退」を押し、生存兵・武将が帰還することを確認。
14. 落城後、新しい城を選択して内政/城主/守備兵が扱えることを確認。

## 特に教えてほしいこと

- Core → Tactical → Core の切替が自然か。
- iPhone横画面でボタンやモーダルが指で押しやすいか。
- 包囲継続が「何が起きているか」一目で理解できるか。
- `落城`と`包囲継続`の違いが明確か。
- Armyの「囲」マーカーが邪魔にならず見つけやすいか。
- 包囲中に季節を進める意味が分かりやすいか。
- 占領後に「新しい領地を手に入れた」という感覚があるか。
- Safariのアドレスバー/ノッチ/ホームインジケータにUIが隠れないか。
