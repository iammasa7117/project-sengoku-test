# Phase UI-1 — Strategic Visual Overhaul

目的は「テストしても何のゲームか分からない」状態を解消し、スマートフォン横画面で城・内政・家臣・登用の意味を一目で理解できるようにすること。

## 採用した画面

1. 城詳細（城画像 / 城主 / 人口 / 守備兵 / 民忠 / 防備 / 城機能 / 主要導線）
2. 内政コマンド（大きなビジュアルタイル）
3. 家臣一覧（仮武将画 / 所属 / 役割 / 4能力 / 忠誠 / 兵力）
4. 在野・登用候補（カード型）

`docs/UI_PHASE1_REFERENCE_MOCK.png` が合意済みの方向性モック。

## アート

今回の城・武将・コマンド画像はすべてUI検証用のオリジナル仮SVG。既存ゲーム作品の画像は使用していない。
正式な武将絵・城絵へ差し替える場合も、HTML構造を変えず `assets/ui/` の素材を置換できる。

## スコープ外

- 建物システム本体
- 城強化コマンド本体
- 在野武将への直接登用ロジック
- 新しいゲームバランス
- Tactical Battleのルール変更

これらは画面上で「準備中」または現行ロジックに接続する形に限定した。
