# Project Sengoku Core v1.0 Release Report

## Release status

Core v1.0 RC1を正式版へ昇格しました。ゲームロジック、バランス、AI、セーブ形式には変更を加えていません。

## Compatibility

- schemaVersion: 10
- gameVersion: core-0.95
- Core v0.95以降の既存セーブ互換経路を維持

## Release-only changes

- 表示名をCore v1.0へ更新
- HTMLタイトルとリリースラベルを正式版へ更新
- デバッグ見出しとプレイレポート名を正式版へ更新
- README、CHANGELOG、静的検査を正式版表記へ更新

## Known limitation

Safari、Chrome、iPhoneでの実機手動操作は、この自動検査環境では未実施です。
