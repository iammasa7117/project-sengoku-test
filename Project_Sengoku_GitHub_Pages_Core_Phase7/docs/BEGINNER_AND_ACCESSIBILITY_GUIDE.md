# 初心者ガイド・操作性ガイド

## 最初のプレイ

1. 「新しい戦を始める」を押します。
2. シナリオ、勢力、難易度を選びます。
3. 初めて遊ぶ場合は「初心者ガイド」を有効のまま開始します。
4. 画面上部の「次の一手」に従って、自勢力の城を選びます。
5. 内政・徴兵・訓練・休養などを実行します。
6. 命令を使い終えたら「季節を進める」を押します。
7. 戦争中の隣接勢力へ侵攻し、全城支配または覇権を目指します。

## 次の一手

案内は現在の状態を毎回確認し、次を優先して表示します。

1. 未解決の重要イベント
2. イベントから開始した操作
3. 未回答の外交提案
4. 初陣軍議
5. 命令を使い切った後の季節進行
6. 自勢力の城選択
7. 兵力が少ない城での徴兵
8. 合法な侵攻
9. 内政または休養

案内は操作を強制しません。別の行動を選んでもゲーム進行に影響はありません。

## 初回チェックリスト

- 戦役画面を確認する
- 自勢力の城を選ぶ
- 家臣に命令を出す
- 季節を一度進める
- メニューを開く

完了状態はセーブされます。メニューの「操作・表示設定」で表示を切り替え、「遊び方」から再開できます。

## キーボード

- `M`: メニュー
- `?` または `/`: 遊び方・用語集
- `G`: 次の一手へ移動
- `Esc`: モーダルを閉じる
- `Ctrl + Shift + D`: デバッグパネル
- `Tab` / `Shift + Tab`: モーダル内の操作項目を循環

城・武将・命令・選択肢は通常のTab移動とEnter/Spaceで操作できます。

## 表示設定

- **文字を大きくする**: 本文と操作要素を拡大します。
- **高コントラスト**: 文字、枠線、背景の差を強めます。
- **動きを減らす**: スクロールやアニメーションを即時表示へ変更します。

設定はゲーム状態と一緒に保存されます。schema 10の旧セーブには初期値が自動補完されます。

## スマートフォン

画面幅1050px以下では下部ナビゲーションを表示します。画面幅620px以下では地図を横スクロールでき、モーダルは画面下部から表示されます。iPhoneのsafe-areaもCSSで確保します。

実機ごとの文字倍率やブラウザ設定により見え方は変わります。操作できない箇所があれば、端末名、ブラウザ名、画面写真、操作手順を記録してください。
