# Phase 10 スマホ実機テスト — 敗走 / 追撃

横画面で`01_START_GAME.html`を開いてください。

## 最短テスト
1. AIを有効にした通常戦役を開始。
2. 敵Armyが自城の最終隣接区間へ入るまで「次季」。
3. 敵Armyをタップ → 「迎撃軍を出す」。
4. 総大将・兵種・兵数を選び迎撃。
5. 次季に街道接触 → Tactical Battleを指揮。
6. 勝利する。
7. 戦報に「🏇 追撃可能」が表示されることを確認。
8. 一度は「追撃する」を選び、追加損害表示を確認。
9. 別プレイでは「追撃せず戻る」を選ぶ。
10. 地図上に敵の「退」旗が残っていることを確認。
11. 「退」旗をタップし「敗走中」「退却路」が表示されることを確認。
12. 次季へ進め、「退」旗が消えて敵の生存兵が自城へ帰還することを確認。

## 見てほしいUX
- 「戦」「迎」「囲」「退」の旗の意味が直感的に分かるか。
- 勝利後に「追撃する / しない」が迷わず理解できるか。
- 追撃のメリット（追加損害）とコスト（総大将疲労）が分かるか。
- 敗走軍が「まだ脅威なのか」「もう攻めてこないのか」が視覚的に分かるか。
- 敗走 → 次季帰城が不自然に長く感じないか。

## 仕様
- Phase 10 v0.1の敗走は原則1Turn。
- 敗走Armyは迎撃/通常野戦/Threat判定の対象外。
- 追撃はPlayer勝利時のみ。
- 追撃はBattle発生Turn中のみ。
- 追撃すると敗走兵へ18%追加損害、総大将fatigue +8。
- 追撃しなくても敗走Armyは次季に帰城する。
