# Phase 2 携帯テスト

推奨: iPhone / Android のSafariまたはChrome、横画面。

## 確認手順

1. ゲーム開始後、自勢力城を選択。
2. `軍勢出陣`をタップ。
3. 侵攻先を選択。
4. Unit 1で総大将・兵種・兵数を設定。
5. 必要ならUnit 2 / 3へ別武将を追加。
6. `軍勢を出陣させる`。
7. 地図上に`軍`マーカーが表示されることを確認。
8. マーカーをタップして軍勢詳細を確認。
9. `季節を進める`。
10. Battle Reportが出て、勝利なら敵城が自勢力化、敗北なら軍勢が出陣元へ帰還することを確認。

## 特に見てほしい点

- Army編成モーダルが指で操作しやすいか。
- 横画面でフォームが窮屈すぎないか。
- Armyマーカーが城と重なって押しづらくないか。
- 地図の横スクロールとArmyマーカー操作が競合しないか。
- Battle Reportが突然すぎないか。
- `1季で隣城へ移動`のテンポが遅く感じるか。

## 現在の意図的制限

- Tactical B5.3にはまだ入りません。
- Army到着戦はLegacy Battle自動解決です。
- Unit兵種は保存されますがLegacy Battle数式にはまだ影響しません。
- 進軍は隣接城のみです。
