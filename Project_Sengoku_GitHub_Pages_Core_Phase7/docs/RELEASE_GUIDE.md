# Project Sengoku Core v1.0 Release Guide

## 起動

1. ZIPを解凍します。
2. `index.html`をChrome、Safari、Edgeなどで直接開きます。
3. ローカルサーバー、npm、インストールは不要です。

## 推奨環境

- デスクトップ: 最新版Chrome、Safari、Edge
- モバイル: 最新版SafariまたはChrome
- JavaScriptと`localStorage`が有効であること

## セーブ

- オートセーブと手動3スロット
- 各スロット3世代バックアップ
- checksumによる破損検知
- 主データ破損時のバックアップ復旧
- JSONエクスポートを端末外バックアップとして推奨

内部互換形式は`schemaVersion: 10`、`gameVersion: core-0.95`を維持します。

## 難易度

- 易しい: 初期資源・兵力・戦闘補正が高く、序盤4季の防衛支援があります。
- 普通: 標準補正。序盤2季の小さな防衛支援があります。
- 難しい: AIの経済・徴兵・攻勢が強く、序盤防衛支援はありません。

## リリース前の実機確認

- 新規ゲーム開始
- 初心者ガイド
- 内政、徴兵、合戦、外交、季節進行
- セーブ、ロード、バックアップ復旧
- 勝利・敗北画面
- Chrome/Safariの`file://`起動
- スマートフォン幅の下部ナビとモーダル

## 既知の制約

- 正式人物、正式物語、正式性格・特性、画像、音楽は未収録です。
- 12城キャンペーンの追加城・第四勢力はシステム検証用の仮コンテンツです。
- ブラウザの保存領域が制限されている場合はJSONエクスポートを利用してください。
- 自動検査環境ではSafari、Chrome、iPhoneによる実操作を行っていません。
