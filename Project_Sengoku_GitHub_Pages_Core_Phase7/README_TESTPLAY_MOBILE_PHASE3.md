# Project Sengoku Phase 3 — 携帯テスト手順

## 推奨
GitHub PagesをiPhone / Androidで開き、横画面で確認してください。

## 最初に見るところ
1. 新しい戦を開始し、自勢力の城を選択。
2. 城詳細に「人口 / 守備兵 / 徴兵上限 / 農業 / 季節の金 / 季節の兵糧」が出ること。
3. 「町づくり」を実行し、収入基盤と人口が増えること。
4. 「開墾」を実行し、農業Lvと人口が増え、季節兵糧の表示が増えること。
5. 「徴兵」で守備兵が増え、その分人口が減ること。
6. 「軍勢出陣」でArmyを作る。Army詳細に「季節維持費 / 季節兵糧」が出ること。
7. 「季節を進める」後、金・兵糧にArmy維持費が反映されること。
