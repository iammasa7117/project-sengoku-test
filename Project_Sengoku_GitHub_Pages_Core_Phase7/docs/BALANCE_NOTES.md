# Core v1.0 Balance Notes

## 目的

Core v1.0 RC1では新しい大型システムを追加せず、序盤即滅亡、長期停滞、AI一強化、難易度差の不明瞭さを抑える最終調整を行いました。

## 難易度差

### 易しい

- 初期資源+25%
- 自軍初期兵力+15%
- 自軍合戦+10%
- AI経済0.84倍、徴兵0.88倍、合戦0.90倍
- 序盤4季の防衛補正
- 1季の対プレイヤーAI侵攻を最大1回に制限

### 普通

- 基本値
- 序盤2季の小さな防衛補正
- 1季の対プレイヤーAI侵攻を最大2回に制限

### 難しい

- 初期資源-12%
- 自軍初期兵力-8%
- 自軍合戦-5%
- AI経済1.16倍、徴兵1.13倍、合戦1.08倍
- 追加AI行動の可能性
- 序盤防衛補正なし

## 停滞対策

戦争中と戦局停滞時はAIの侵攻必要兵力比を段階的に下げます。下限を設定し、無謀な攻撃の連続は防ぎます。外交側の12季停滞再評価も維持します。

## 一強化対策

城数で大きく先行するAI勢力には、小さな経済・徴兵・攻撃補正の抑制を適用します。1城勢力などの劣勢勢力には、小さな経済・徴兵・防衛補正を適用します。

## 落城後

攻略直後の城は士気が低下します。連続侵攻の拠点にはできる一方、直後の反撃に対して完全な状態ではありません。

## 互換性

- セーブschemaは変更していません。
- 正式コンテンツは追加していません。
- 既存の合戦、外交、イベント、忠誠、捕虜処理を置換していません。
