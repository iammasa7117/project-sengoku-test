# Phase 9 スマホ実機テスト

## 開き方
GitHub Pages版をiPhone/Androidで開き、横画面にしてください。

## 最短テスト
1. AIを有効にした通常戦役を開始。
2. 敵Armyが自城へ進軍するまで「次季」を進める。
3. 地図上の赤い敵Armyをタップ。
4. 最終隣接区間に入ると「迎撃可能」と表示されることを確認。
5. 「迎撃軍を出す」を押す。
6. 総大将・兵種・兵数を選択して「迎撃に出る」。
7. 地図に「迎」旗の自軍Armyが出ることを確認。
8. 次季へ進み、同じ街道で接触するとTactical Battleが開くことを確認。
9. 会戦を指揮し、Coreへ戻る。
10. 勝利時は敵Armyが撤退し自城が無傷、敗北時は敵Armyが侵攻を継続することを確認。

## 見てほしい点
- 敵Armyを見て「迎撃できる/まだできない」が理解できるか。
- 迎撃ボタンが指で押しやすいか。
- 迎撃編成画面がUI-2のデザインと統一されているか。
- Core → Tactical → Coreの切替が自然か。
- 街道野戦と城攻略戦の違いが結果画面で分かるか。

※迎撃は現在、敵軍が防衛城の隣接する最終区間に入った時だけ可能です。これはv0.1の意図的な制約です。
