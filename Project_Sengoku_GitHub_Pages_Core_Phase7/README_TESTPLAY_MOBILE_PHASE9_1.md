# Phase 9.1 スマホ実機テスト

## 最短確認
1. `01_START_GAME.html`をiPhone/AndroidまたはPCブラウザで開く。
2. AI有効の通常戦役を開始する。
3. 敵Armyが自城への最終隣接区間に入るまで「次季」を進める。
4. 地図上の敵Armyをタップする。
5. 「INTERCEPT / 迎撃可能」と「迎撃軍を出す」が表示されることを確認する。
6. 迎撃軍を編成して出陣する。
7. 次季に同じ街道で接触し、Tactical野戦を指揮する。
8. Coreへ戻り、勝利時は敵軍撤退・防衛城無傷、敗北時は敵軍の侵攻継続を確認する。
9. 同じ季節に別Armyが存在する場合、そのArmyの移動がTactical割込みによって消失していないことを確認する。

## 追加確認
- 迎撃圏外の敵ArmyをタップしてもJavaScript Errorが出ない。
- 迎撃圏外では「迎撃軍を出す」ボタンが出ない。
- 戦報を閉じた時に別のpending Tacticalがある場合、その会戦へ進める。
- Save/Load後にpending Tacticalを再開できる。
