命令

部隊を押したまま指で経路をなぞり、指を離して移動後の向きを選べます。

B5.2 新しい移動操作

  1. 自軍部隊の上に指を置く
  2. 押したまま、移動させたい経路を自由になぞる
  3. 黄色い経路線を確認して指を離す
  4. 表示される8方向の矢印から、移動後に向く方向を選ぶ
  5. 部隊は経路に沿って移動し、到着後に指定方向を向く
  6. 従来の「移動 / 攻撃 / 突撃」ボタンもそのまま使用可能
