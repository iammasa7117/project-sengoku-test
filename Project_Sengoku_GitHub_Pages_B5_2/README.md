# Project Sengoku Tactical B5.2 — GitHub Pages Test Build

Mobile-first test build for Project Sengoku Tactical Battle Prototype B5.2.

## GitHub Pages

Publish this repository from the `main` branch and repository root (`/`).
The game entry point is `index.html`.

## iPhone

Open the GitHub Pages URL in Safari. For faster repeat testing, use Safari's Share menu and add the site to the Home Screen.

## Controls

- Touch and hold a friendly unit, then trace the desired route with your finger.
- Release to open the 8-direction facing selector.
- Choose the direction the unit should face after arriving.
- Existing Move / Attack / Charge / Retreat / Wait controls remain available.

This build is for testing and balance iteration, not a release build.
